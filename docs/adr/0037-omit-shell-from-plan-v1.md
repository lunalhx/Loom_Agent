# Omit Shell from Plan v1

Plan v1 omits `run_shell` from the Effective Tool Catalog and Runtime Gate rejects any hidden, stale, or fabricated Shell invocation while the Run Mode Snapshot is Plan. Tool Approval cannot override this denial. Repository exploration remains available through structured read tools such as `read_file`, `list_files`, and `search`, plus separately authorized structured External Reads. Read-only command classification, compound-shell parsing, Shell Evidence Adapters, and general OS sandboxing are deferred to a later Shell capability; introducing them must preserve Plan Mode's hard Repository State and external-mutation boundary. This keeps the initial Plan implementation complete and enforceable without treating prompt instructions or the current unconstrained `/bin/sh -c` runner as a security boundary.
