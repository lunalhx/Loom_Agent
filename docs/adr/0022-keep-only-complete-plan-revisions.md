# Keep only complete Plan revisions

Status: Accepted.

Every Plan Submission persists a complete, self-contained document snapshot; Plans have no Draft status and revisions are not partial patches. Materially unresolved user decisions remain in ordinary conversation, while explicit assumptions and non-blocking risks may appear in the document, and the prior Current Plan stays unchanged until a complete replacement revision commits. This keeps Current Plan consistently eligible for Handoff without requiring Runtime to interpret Markdown for semantic completeness.
