# Require an explicit Plan Submission action

Status: Accepted.

Creating or revising a Plan requires a dedicated protocol-level Plan Submission action. A normal final answer in Plan Mode may answer a question, request clarification, or report research without changing the Current Plan. This avoids heuristic classification of Markdown as domain state and gives persistence and clients an unambiguous event to validate, render, version, and audit; the concrete wire syntax remains a separate decision.
